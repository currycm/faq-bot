# ============================================================================
# 依赖版本策略（2026-09 写明，避免后来人"顺手钉死"）
#   本文件**故意**用 >= 而不是 ==：这是一个**应用**，不是库；把精确版本钉死在
#   requirements.txt 里会让安全更新需要手动跟。CI 每次都用最新满足版本装一遍，
#   上游发坏版本会立刻在 CI 变红 —— 属于"快速失败"。
#
#   需要可复现环境（生产镜像）时请生成**锁文件**，并且必须在 Docker 构建环境里做：
#       docker build -t faq-bot . #         && docker run --rm --entrypoint pip faq-bot freeze > requirements.lock
#       # 之后可 pip install -r requirements.lock
#
#   !!! 不要在本地 Anaconda / 开发机直接 pip freeze 生成锁文件 !!!
#   本机实测会把这个 conda 环境里几百个无关包、以及 Python 3.13 时代的版本一起
#   钉进来（例如 redis 装成了 8.0.0b2 这种 beta 版），而镜像是 python:3.11-slim，
#   锁出来的东西是错的 —— 比不锁更危险。
# ============================================================================
