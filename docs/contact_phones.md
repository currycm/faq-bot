## 附录：怎么重新验一遍

```bash
# 直接看页面（沙箱/本机均可，走系统代理）
curl -sk https://xsc.niit.edu.cn/3800/list.htm | iconv -f utf-8 -t utf-8 | grep -o '858[0-9]\{5\}'
curl -sk https://xxh.niit.edu.cn/ | grep -o '858[0-9]\{5\}'
curl -sk https://www.niit.edu.cn/67/7e/c4047a26494/page.htm | grep -o '025-[0-9]\{8\}'
```

更稳的做法是复用项目爬虫：`scripts/crawl_notices.py` 已支持站群列表页抓取，
把上述三个「联系方式页」加进 `LIST_PAGES` 即可纳入日常抓取范围。

> **注意裸 grep 的假阳性**：上面第三条命令在数智化处首页会多出一个 `85820006` ——
> 那其实是简道云链接 `…5dce67b27885820006d112d5` 里的一段数字，不是电话。
> 本台账正文的号码是用「先剥掉 HTML 标签、只扫可见文本 + 校验前后是否出现
> 电话/热线/联系/报修等词」的方式提取的，所以没有这个问题。裸 grep 只适合快速复核。

> 号码会变。本台账写的是 2026-09-11 的快照，对外使用前建议重跑一次附录命令。
