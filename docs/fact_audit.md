## H. 怎么用本文件

- 任何时候修改 `data/qa_corpus.json` 后，先重跑 `python scripts/report_unsourced.py`，
  同步更新 C 节统计；改动 **A 节中出现的硬事实** 时，回到本文件 G.1 / G.2 列表划掉对应项。
- `KNOWN_WRONG_DEPT` 一旦扩列，**不要忘了把脚本里的常量同步改**：
  `scripts/report_unsourced.py` 中的 `KNOWN_WRONG_DEPT = {…}`。
- 本文件**不**自动重生。下次"按官方信息修语料"的工作流建议：先写本文件 G.1 → 再改语料 → 再 commit，
  这样 commit message 里能直接引用本文件的章节号。
